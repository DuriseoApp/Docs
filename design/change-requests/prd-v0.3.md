## 디자인 채팅에 붙여넣을 내용

```
PRD가 v0.3으로 바뀌어서 캔버스를 수정해 줘. 기존 화면은 지우지 말고 "이전 버전" 줄로 옮긴 뒤 새 화면을 만들어 줘.
디자인 시스템의 토큰과 컴포넌트만 쓰고, 새 색이나 새 컴포넌트가 필요하면 만들기 전에 먼저 물어봐 줘.
화면마다 보드 이름 앞에 화면 ID를 붙여 줘 (예: "SCR-CAL-03 일정 작성").

[수정]
1. SCR-START-01 시작: Naver 로그인을 빼고 "Google로 시작", "Kakao로 시작", "게스트로 시작" 세 버튼으로.
2. SCR-COUPLE-01 커플 연결: "초대코드 만들기", "초대코드 입력하기" 아래에 "혼자 시작하기"를 추가.
   게스트가 이 화면에 오면 연결 대신 "계정 연동이 필요해요" 안내와 연동 버튼을 보여주는 상태도 그려 줘.
3. SCR-MEMO-01 메모 목록: 고정 개수 제한이 없어졌어. "핀은 최대 3개까지" 문구를 모두 빼 줘.
   고정 3개 이하면 모두 보이고, 4개 이상이면 최근 고정한 3개 + "더보기"를 보여줘.
   디자인 시스템 말투 예시에 있는 같은 문장도 빼 줘.
4. SCR-CAL-03 일정 작성: 대상 선택은 "나"와 "함께" 두 개만 (상대는 고를 수 없어). 기본은 나.
   개인 공간에서는 대상 선택이 보이지 않는 상태도 그려 줘.
5. SCR-CAL-03 일정 작성, SCR-MEMO-04 메모 작성: "상대에게 알림 보내기" 스위치 추가 (기본 켜짐).
   커플 공간에서 새로 만들 때만 보이고, 개인 공간과 수정할 때는 보이지 않아.

[새 화면]
6. SCR-MEMO-02 고정 메모 전체: "더보기"를 누르면 나오는 화면. 고정 메모 전체를 최근 고정순으로.
7. SCR-ANNIV-01 기념일 목록: 오늘 이후 기념일(자동 + 직접)을 가까운 순으로, 항목마다 남은 일수(D-N). 직접 기념일 추가 버튼.
8. SCR-ANNIV-02 직접 기념일 작성: 이름, 날짜, "매년 반복" 스위치. (캔버스에 이미 있으면 확인만)
9. SCR-COUPLE-04 연결 완료: 연결 완료 안내, 사귄 날 입력, 내 기존 기록 "가져오기 / 가져오지 않기",
   "가져오지 않기"를 고르면 나오는 삭제 확인 다이얼로그.
10. SCR-SET-01 전체 메뉴의 게스트 상태: 상단에 "앱을 삭제하거나 기기를 바꾸면 데이터를 복구할 수 없습니다" 안내와 계정 연동 버튼. 로그아웃 메뉴 없음.
11. 연결 해제 확인 다이얼로그: 두 사람 모두 빈 개인 공간에서 다시 시작하고, 30일 안에 다시 연결하면 복구된다는 안내.
    확인하면 앱이 초기화되고 "연결 방법 선택"(SCR-COUPLE-01)으로 가는 흐름을 화살표로 표시해 줘.
12. 탈퇴 확인 다이얼로그: 개인 공간이면 즉시 삭제, 커플 공간이면 연결 해제 후 삭제된다는 안내.

[확인]
13. SCR-SET-04 프로필 수정(이름, 사진, 사진 선택 시트: 앨범·카메라·삭제)과 SCR-SET-03 우리 색상이 캔버스에 있는지 확인하고, 없으면 만들어 줘.

다 끝나면 바뀐 화면 ID 목록과, 디자인 시스템(토큰·컴포넌트)에 바뀐 점이 있으면 그 목록을 정리해 줘.
```
