# 디자인 변경 요청서: PRD v0.5

> 상태: 반영 완료 (2026-10-22, 캔버스 버전 35)
> 기준 문서: 둘이서 PRD v0.5 (`docs/PRD.md`), `docs/SCREENS.md`, `sync/prd-v0.5.md`
> 작성일: 2026-10-21

claude.ai 프로젝트 채팅에서 "디자인 반영해줘"라고 하면 `/design-sync`가 아래 내용대로 디자인 캔버스를 고치고, 이 파일의 상태를 "반영 완료"로 바꿔요.

이번 변경은 2026-10-21 문서 점검에서 찾은 허점을 사용자가 정한 결과예요 (PRD D-48~D-66). 화면에 보이는 바뀐 점은 연결 완료 시트, 개인 공간 캘린더 앱바와 기념일 표시, 일정 시작·종료 행, 메모 작성자 닉네임, 알림 문구 예시, 동의 문구예요.

---

## 디자인 변경 내용

```
PRD가 v0.5로 바뀌어서 캔버스를 수정해 줘. 기존 화면은 지우지 말고 "이전 버전" 줄로 옮긴 뒤 새 화면을 만들어 줘.
디자인 시스템의 토큰과 컴포넌트만 쓰고, 새 색이나 새 컴포넌트가 필요하면 만들기 전에 먼저 물어봐 줘.
화면마다 보드 이름 앞에 화면 ID를 붙여 줘 (예: "SCR-CAL-03 일정 작성").
문구는 디자인 시스템 말투(해요체, 결과가 보이는 동사, 이모지 없음)를 따라 줘. 아래에 따옴표로 적은 문구는 그대로 써 줘.
[상대 이름], [기념일 이름] 같은 대괄호는 자리표시야. 실제 이름으로 바꾸지 말고 그대로 두거나 샘플 이름을 넣어 줘.

2. SCR-CAL-01 캘린더 홈 (보드: Calendar.dc.html, CalendarExpanded.dc.html) — PRD D-65, FR-CAL-01 AC2
   - 선택한 날의 목록 순서를 기념일 → 종일 일정 → 시간 일정 → 메모로 바꿔 줘.
   - 기념일은 목록 맨 위에 "기념일" 표시와 함께 카드로 보여 줘. 구성은 이름, 자동 기념일이면 "D+200" 같은 D+N, 직접 기념일이면 만든 사람의 사람 색 점(라벨 나·상대와 함께)이야. 누르면 SCR-ANNIV-01로 간다는 흐름을 화살표로 표시해 줘.

   - 선택한 날(`brand-500` 채움) 위에서 고리가 안 보이면 기존 토큰(`on-brand`)으로 보이게 하고, 어떻게 했는지 알려 줘.
   - 한 날에 점과 고리가 같이 있을 때의 개수 규칙은 PRD에 없어. 점 최대 3개는 그대로 두고, 고리를 넣어서 3개를 넘는 날이 생기면 어떻게 그렸는지 알려 줘.
   - 펼친 상태(CalendarExpanded)도 같은 고리를 날짜 칸에 보여 줘. 날짜 있는 메모는 이미 막대로 그려져 있어서 그대로 둬.
   - 앱바의 알림 버튼 점, 날짜 점·목록의 메모 표시는 그대로 둬.
3. SCR-CAL-02 일정 상세 (보드: EventDetail.dc.html, EventDetailPartner.dc.html) — PRD D-64, FR-CAL-02 AC1

   - 종일 일정은 두 줄 모두 날짜만 보여 (시작 "10월 17일 (토)", 종료 "10월 18일 (일)").
   - 상대 일정(EventDetailPartner)과 삭제 확인(EventDetailDialog)의 일시 줄도 같은 모양으로 맞춰 줘. 나머지 구성은 그대로야.
4. SCR-CAL-03 일정 작성·수정 (보드: AddEvent.dc.html, AddEventSolo.dc.html) — PRD D-64, D-59, FR-CAL-02 AC1·AC4

8. SCR-NOTI-01 알림 목록 (보드: Notifications.dc.html, NotificationsRead.dc.html) — PRD D-55, D-53, 8장 알림 문구
   - 기념일 알림 샘플을 두 가지로 보여 줘.
     · 자동 기념일: 제목 "오늘은 200일이에요", 본문 "함께한 지 D+200"
     · 직접 기념일(매년 반복, 두 번째 해부터): 제목 "오늘은 [기념일 이름]이에요", 본문 "3번째 맞는 날이에요". (반복이 아니거나 첫 해는 본문이 "오늘이에요"야.)
   - 상대 탈퇴 알림 샘플을 추가해 줘: 제목 "[상대 이름]님이 탈퇴해 연결이 해제됐어요", 본문 "함께 쓴 기록은 더 이상 볼 수 없어요". 연결 해제 알림과 같은 종류 아이콘을 써. 복구 안내 문구는 넣지 마.
   - 연결 해제 알림 샘플(제목 "[상대 이름]님이 연결을 해제했어요", 본문 "30일 안에 다시 연결하면 기록이 돌아와요")은 그대로 둬.
   - 안 읽음 점, 읽음 상태, 빈 상태는 그대로야.

10. SCR-COUPLE-04 연결 완료 시트 (제안 보드: CalendarLinkedSheet.dc.html, 시트 위 다이얼로그 상태: CalendarLinkedSheetDialog.dc.html) — PRD D-48, D-49, FR-COUPLE-02 AC1, FR-COUPLE-03 AC4, FR-COUPLE-04 AC3
   - 캘린더 홈(SCR-CAL-01) 위에 하단 시트가 떠 있는 모양으로 그려 줘. 캘린더는 시트 뒤에서 어둡게 보여. 시트 모양은 기존 사진 시트(ProfilePhotoSheet.dc.html)와 다이얼로그 모양을 참고해 줘. 전체 화면이 아니야.
   - 시트 구성(위에서 아래로)
     · 제목 "[상대 이름]님과 연결됐어요"
     · "처음 만난 날" 날짜 선택 칸(자리표시 "날짜를 골라 주세요")과 안내 "D-day와 기념일이 이 날을 1일로 계산돼요. 둘 중 누구든 나중에 바꿀 수 있어요."
     · [나중에 하기] 버튼 (처음 만난 날을 건너뛰는 버튼)
     · "혼자 쓴 기록" 제목, 개수 안내 "일정 [N]개, 기념일 [N]개, 메모 [N]개가 있어요.", 선택 카드 [가져오기] / [가져오지 않기] (카드 설명은 기존 그대로: "함께 쓰는 캘린더와 메모로 옮겨요" / "혼자 쓴 기록은 삭제돼요")
     · 안내 "내 기록만 정해요. 상대의 기록은 상대가 정해요."
     · [시작하기] 버튼 (기존 [둘이서 시작하기]에서 이름이 바뀌었어)
   - 겹친 원 그림과 설명 문구("시작하기 전에 두 가지만 정해 주세요.")는 시트에 넣지 않아.
   - 혼자 쓴 기록이 있으면 [가져오기]나 [가져오지 않기]를 고르기 전에는 시트를 닫을 수 없어. 그래서 닫기 버튼을 두지 마.
   - 미래 날짜는 고를 수 없어. 날짜 선택 칸에서 오늘 이후 날짜가 비활성인 모습이 필요하면 알려 줘.
   - 확인 필요: 선택 카드의 처음 모양(둘 중 하나가 미리 선택돼 있는지)과, 고르기 전 [시작하기]를 어떻게 보여줄지는 PRD에 정해진 게 없어서 확인 중이야. 이 두 가지는 그리기 전에 먼저 물어봐 줘.
   - 시트 위 다이얼로그 상태(CalendarLinkedSheetDialog): [가져오지 않기]로 시작하면 "혼자 쓴 기록을 삭제할까요?" [취소] [삭제하고 시작]. 문구와 버튼은 기존 ConnectedDialog와 같아. 시트 위에 떠 있는 모양만 새로 그려 줘.
   - 혼자 쓴 기록이 없는 상태(기록 영역이 없고 시트를 닫을 수 있음)는 이번에 그리지 않아. 디자인 없음, SCREENS.md 기준이야.
11. SCR-CAL-03 일정 수정 · 상대가 '함께' 일정을 수정할 때 (제안 보드: AddEventPartnerEdit.dc.html) — PRD D-52, FR-CAL-03 AC4
   - 상대가 만든 '함께' 일정을 내가 수정하는 화면이야. 앱바 제목은 수정 모드에 맞게 "일정 수정"으로.
   - 대상 선택 [나 | 함께]를 보이지 않게 해 줘. 대상은 작성자만 바꿀 수 있어.
   - 시작·종료 행, 내 알림, 일정 메모는 4번과 같고, 수정할 때는 "상대에게 알림 보내기" 스위치가 없어.
   - 대상 선택이 빠진 자리와 "누구의 일정인가요?" 제목, 색상 변경 링크, 안내 "함께 일정은 두 사람 모두 수정할 수 있어요."를 어떻게 처리했는지 알려 줘. PRD는 "대상 선택이 보이지 않는다"까지만 정했어. 읽기 전용 표시가 필요한지는 정하지 말고 알려 줘.
12. SCR-ANNIV-01 기념일 목록 · 개인 공간 (제안 보드: AnniversariesSolo.dc.html, 빈 상태: AnniversariesSoloEmpty.dc.html) — PRD D-54, FR-ANNIV-04 AC2
   - 함께한 날 카드(겹친 원, "함께한 지", D+N, "처음 만난 날")를 빼고 "다가오는 기념일 · 가까운 순" 목록만 보여 줘. 앱바(뒤로, "기념일", 추가 버튼)는 그대로야.
   - 목록에는 직접 기념일만 있어 (D-N 배지, "내가 만든 기념일 · 매년", 사람 색 점은 나). 자동 기념일은 없어.
   - 빈 상태: "아직 기념일이 없어요" + [기념일 추가] 버튼.
   - 진입은 SCR-CAL-01 앱바의 "기념일 ›" 링크(9번)라는 흐름을 화살표로 표시해 줘.
13. SCR-START-01 시작 · 다른 기기 로그인으로 로그아웃됨 (제안 보드: MainSessionReplaced.dc.html) — PRD D-51, FR-AUTH-02 AC3
```
