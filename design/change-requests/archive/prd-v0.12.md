# 디자인 변경 요청서: PRD v0.12

> 상태: 반영 완료 (2026-11-08, 캔버스 버전 43)
> 기준 문서: 둘이서 PRD v0.12 (`docs/PRD.md`), `docs/SCREENS.md`, `sync/prd-v0.12.md`
> 작성일: 2026-11-08

claude.ai 프로젝트 채팅에서 "디자인 반영해줘"라고 하면 `/design-sync`가 아래 내용대로 디자인 캔버스를 고치고, 이 파일의 상태를 "반영 완료"로 바꿔요.

이전 요청서(v0.3~v0.11)는 모두 반영 완료예요 (최신은 2026-11-06, 캔버스 버전 41).

이번 변경은 서버·Android 작업을 시작하기 전에 문서의 빈 곳과 모순을 점검한 결과를 사용자가 정한 것이에요 (PRD D-118, D-128, D-129, D-145, D-147, D-148, D-150~D-152). **새 화면 ID는 1개(SCR-SET-05)예요.** 나머지는 이미 있는 화면의 새 상태와 고침이에요. 요청은 10건이고 확인 항목이 2건 더 있어요. 새 보드는 6개이고, 이미지가 있는 상태는 `/design-sync`가 이름을 정해요 (아래 "이미지 이름").

보드 값과 문구는 지금 캔버스(버전 41)가 맞아요. 이번에 바뀐 문구와 규칙은 `docs/SCREENS.md`에 적었고, 아래에 적은 곳만 고쳐요.
