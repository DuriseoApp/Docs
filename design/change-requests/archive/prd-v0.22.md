# 디자인 변경 요청서: PRD v0.22

> 상태: 반영 완료 (2026-11-25, 캔버스 버전 46)
> 기준 문서: 둘이서 PRD v0.22 (`docs/PRD.md` FR-APP-01·02, D-176~D-182), `docs/SCREENS.md` SCR-APP-01·SCR-APP-02·"운영", `sync/prd-v0.22.md`
> 작성일: 2026-11-25

claude.ai 프로젝트 채팅에서 "디자인 반영해줘"라고 하면 `/design-sync`가 아래 내용대로 디자인 캔버스와 `design/design-system.md`를 고치고, 이 파일의 상태를 "반영 완료"로 바꿔요.

이전 요청서(v0.3~v0.21)는 모두 반영 완료예요 (최신은 2026-11-25, 캔버스 버전 45, `design/change-requests/archive/prd-v0.21.md`).

이번 변경은 운영용 팝업 두 개를 새로 그리는 거예요. **새 화면 ID가 2개예요** (SCR-APP-01 장애 팝업, SCR-APP-02 업데이트 팝업). 둘 다 가운데 다이얼로그이고, 기존 다이얼로그(design-system "다이얼로그")와 같은 모양에서 시작해요. 기존 화면과 보드는 바꾸지 않아요. 새 보드는 2개, 새 일러스트(기본 이미지)는 4종이에요.

팝업은 로그인 전을 포함한 모든 화면 위에 떠요(D-178). 그래서 뒤 화면은 보드마다 하나만 골라 그려요(아래 "뒤 화면").
