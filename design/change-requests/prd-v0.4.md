# 디자인 변경 요청서: PRD v0.4

> 상태: 반영 완료 (2026-10-18, 캔버스 버전 30)
> 기준 문서: 둘이서 PRD v0.4 (`docs/PRD.md`), `docs/SCREENS.md`
> 작성일: 2026-10-18

claude.ai 프로젝트 채팅에서 "디자인 반영해줘"라고 하면 `/design-sync`가 아래 내용대로 디자인 캔버스를 고치고, 이 파일의 상태를 "반영 완료"로 바꿔요.

이번 변경은 디자인 핸드오프(2026-10-18)에서 찾은 "PRD와의 차이" 10건을 사용자가 정한 결과예요. 디자인과 PRD가 다르던 곳을 PRD에 맞추거나 PRD를 디자인에 맞췄어요.

---

## 디자인 변경 내용

```
PRD가 v0.4로 바뀌어서 캔버스를 수정해 줘. 기존 화면은 지우지 말고 "이전 버전" 줄로 옮긴 뒤 새 화면을 만들어 줘.
디자인 시스템의 토큰과 컴포넌트만 쓰고, 새 색이나 새 컴포넌트가 필요하면 만들기 전에 먼저 물어봐 줘.
화면마다 보드 이름 앞에 화면 ID를 붙여 줘 (예: "SCR-CAL-03 일정 작성").
문구는 디자인 시스템 말투(해요체, 결과가 보이는 동사, 이모지 없음)를 따라 줘.

[수정]
1. SCR-CAL-01 캘린더 홈 (보드: Calendar.dc.html, CalendarExpanded.dc.html) — PRD FR-CAL-01 AC2·AC4, D-38, D-39
   - 앱바의 알림 버튼은 그대로 두고, 안 읽은 알림이 있을 때 버튼에 "안 읽음 점"을 추가해 줘. 점이 없는 상태(모두 읽음)도 보여 줘.
   - 선택한 날의 목록 순서는 종일 일정·기념일 → 시간 일정 → 메모야. 메모는 맨 아래에 "메모" 표시와 함께 나와.
   - 달력 날짜 아래 점에 날짜가 있는 메모도 포함돼 (최대 3개는 그대로).
   - 펼친 상태(CalendarExpanded)에서 날짜 있는 메모를 어떻게 보여줄지는 기존 컴포넌트로 먼저 제안해 줘.
2. SCR-COUPLE-02 초대코드 만들기 (보드: InviteCreate.dc.html, 새 상태 보드 제안: InviteCreateCooldown.dc.html) — PRD FR-COUPLE-01 AC1·AC3, D-05
   - 코드 칸은 6칸 그대로(이미 6자리야). 영문 대문자와 숫자만 보여.
   - 남은 시간 문구를 "24시간 동안 유효 · 23시간 41분 남음"에서 "10분 동안 유효 · N분 N초 남음"으로.
   - [코드 새로 만들기] 버튼의 대기 상태를 새로 그려 줘. 만든 지 1분이 안 됐으면 버튼이 비활성이고 "N초 뒤에 다시 만들 수 있어요"가 보여. 1분이 지나면 버튼이 켜져.
3. SCR-COUPLE-04 연결 완료 (보드: Connected.dc.html, ConnectedDialog.dc.html) — PRD D-40
   - "사귄 날"을 모두 "처음 만난 날"로. 안내 문구와 다이얼로그에도 있으면 같이 바꿔 줘.
4. SCR-ANNIV-01 기념일 목록 (보드: Anniversaries.dc.html) — PRD D-40
   - 함께한 날 카드의 "사귄 날 <날짜>"를 "처음 만난 날 <날짜>"로.
5. SCR-MEMO-01 메모 목록 (보드: Memo.dc.html) — PRD D-41, FR-MEMO-01 AC3
   - 앱바의 검색 버튼을 빼 줘 ("메모장" 제목만).
   - 핀 카드의 "상대 읽음 / 아직 안 읽음" 표시와 NEW 배지를 빼 줘.
   - 체크리스트 진행("체크리스트 · 2/5 완료")이 있으면 빼 줘.
   - 핀 카드와 메모 행에 메모 날짜가 있을 때만 날짜를 보여 줘. 작성일과 메모 날짜가 헷갈리지 않게 라벨이나 기존 아이콘(달력)으로 구분해 줘. 메모 날짜가 없는 메모도 같이 보여 줘.
6. SCR-MEMO-02 고정 메모 전체 (보드: PinnedAll.dc.html) — PRD D-41, FR-MEMO-01 AC3
   - 핀 카드의 읽음 표시와 NEW 배지를 빼고, 메모 날짜가 있을 때만 날짜를 보여 줘 (5번과 같은 방식).
7. SCR-MEMO-04 메모 작성·수정 (보드: AddEventMemo.dc.html, 새 상태 보드 제안: AddEventMemoDate.dc.html) — PRD FR-MEMO-02 AC3, FR-MEMO-03 AC1, D-38
   - 날짜 행을 기본으로 보이지 않게 하고, 그 자리에 [날짜 추가] 버튼을 둬 줘.
   - [날짜 추가]로 날짜를 고른 상태를 새로 그려 줘. 버튼이 날짜 행으로 바뀌고, 행 안에 날짜를 빼는 제거 버튼이 있어 (접근성 라벨 "날짜 빼기"). 날짜 행을 누르면 날짜를 바꿀 수 있어.
   - 체크리스트 편집은 없어 (범위 밖). 지금 디자인 그대로 두면 돼.
8. SCR-SET-01 전체 메뉴의 프로필 카드 (보드: MenuGuest.dc.html, 새 상태 보드 제안: MenuSolo.dc.html, 연결된 커플 상태는 Menu.dc.html) — PRD FR-SET-01, 사용자 결정(핸드오프 차이 #8)
   - 게스트와 혼자(연결 전) 상태의 프로필 카드에는 상대가 없어. 내 아바타 + 점선 원 "아직 없음" + [상대와 연결하기] 버튼으로 바꿔 줘.
   - 이 상태에서는 D-day, "처음 만난 날" 영역과 [처음 만난 날 수정] 버튼을 숨겨. [내 프로필 수정]은 그대로 둬.
   - [상대와 연결하기]는 SCR-COUPLE-01로 가고, 게스트면 로그인 안내(ConnectGuest.dc.html 상태)가 나오는 흐름을 화살표로 표시해 줘.
   - 연결된 커플 상태(Menu.dc.html)의 프로필 카드는 지금 그대로 두고, 이 보드가 어떤 상태인지 알려 줘.
9. SCR-SET-03 우리 색상 (보드: ColorSettings.dc.html) — PRD D-41, FR-CAL-04 AC2
   - [직접 고르기] 버튼을 빼 줘. 12색 중에서만 골라.

[새 화면]
10. SCR-NOTI-01 알림 목록 (제안 보드: Notifications.dc.html, 빈 상태 보드: NotificationsEmpty.dc.html) — PRD FR-NOTI-05, D-39
    - 진입은 SCR-CAL-01 앱바의 알림 버튼이야. 앱바는 뒤로 버튼 + "알림".
    - 최근 30일 알림을 최신순으로. 항목마다 종류 아이콘, 제목, 본문, 받은 시각, 안 읽음 점이 있어. 읽은 항목은 점이 없어.
    - 알림 종류는 일정 알림, 상대 일정·메모 추가, 메모 고정, 기념일, 연결, 해제야. 종류 아이콘은 디자인 시스템의 기존 아이콘(알림 종, 달력, 메모, 핀, 링크, 사람) 안에서 골라 줘.
    - 항목을 누르면 읽음 처리되고 관련 화면(일정 상세, 메모 상세, 기념일 목록, 설정)으로 간다는 흐름을 화살표로 표시해 줘.
    - 안 읽은 항목이 섞인 상태 한 장, 모두 읽은 상태 한 장, 빈 상태 한 장. 빈 상태 문구: "최근 30일 동안 받은 알림이 없어요"
    - 제목·본문 샘플은 아직 정해진 문구가 없으니 자리표시로 써 줘.

    - 수정·삭제는 작성자에게만 보여(대상이 '함께'면 두 사람 모두). 내 일정과 상대 일정(수정·삭제 없음) 상태를 둘 다 그려 줘.
    - 일정 알림 선택지: 시간 일정은 없음·정시·10분 전·1시간 전·1일 전, 종일 일정은 없음·당일 오전 9시·1일 전 오전 9시. 내 설정만 보여.

12. SCR-MEMO-03 메모 상세 (제안 보드: MemoDetail.dc.html) — PRD 5장, FR-MEMO-03, FR-MEMO-05, FR-MEMO-06, D-38
    - 제목, 본문, 메모 날짜(있으면), 작성자 닉네임, 고정 버튼, 즐겨찾기 버튼. 체크리스트는 없어.
```

### 18. 새 토큰·컴포넌트

새 색은 만들지 않았어요. 아래 모양은 기존 토큰 조합이고, 사용자 결정으로 디자인 시스템에 컴포넌트로 등록했어요 (2026-10-18, 디자인 시스템 버전 8: Badge의 `dr-unread`, Chip의 `dr-date-chip`, 새 NotificationItem `dr-noti`). 알림 행 메타 글자는 `brand-50` 위 대비 때문에 `ink-500` 대신 `ink-600`으로 맞췄어요.

- 안 읽음 점(알림 버튼, 알림 목록): `brand-500`, 지름 8. 알림 버튼 점은 흰 테두리 2
- 안 읽은 알림 행: 배경 `brand-50`, 아이콘 원 `brand-100` + `brand-700`. 읽은 행은 `surface-0`, 아이콘 원 `surface-100` + `ink-600`
- 메모 날짜 칩(작성일과 구분): 달력 아이콘 + 날짜, 배경 `surface-100`(카드 위에서는 `surface-0`), 글자 `ink-700`
- 일정 알림 선택 칩: 메모 정렬 칩과 같은 모양(선택 `ink-900` 채움)
