# 둘이서

둘이 함께 쓰는 캘린더와 메모. 커플 정보 공유 앱 **둘이서**(Android 패키지 `com.duriseo.android`)의 디자인 시스템이에요. 화면 데모(로그인 → 연결 → 캘린더 → 메모 → 색상 설정)에서 쓴 값을 그대로 토큰과 컴포넌트로 옮겼어요.

> 이 파일은 claude.ai 디자인 캔버스의 디자인 시스템을 옮긴 것이에요. 실제 값(색 코드 등)은 `design/tokens.json`이 기준이고, `/design-sync`가 갱신해요.
> 갱신: 2026-11-06 (PRD v0.11, 캔버스 버전 41) — 컴포넌트 명세는 `design/source/` 보드 값에서 읽었어요. 토큰 값은 바꾸지 않았어요. 보드 값이 토큰과 다르면 보드 값을 그대로 적고 다르다고 표시했어요. 변경 이력은 git에 있어요.

## 원칙

1. **겹치는 자리.** 로고는 나(주황)와 상대(파랑)가 겹치고, 겹친 부분이 '함께'(보라)예요. 화면에서도 같은 생각을 따라요. 따로 쓴 것과 함께 쓴 것이 한눈에 구분돼야 해요.
2. **색은 사람이다.** `person-*` 색은 꾸밈이 아니라 "누구의 것인지"를 알려줘요. 사용자가 언제든 바꿀 수 있으니 색만으로 의미를 전달하지 않고, 항상 라벨(나·상대·함께)을 함께 둬요.
3. **다정하지만 군더더기 없이.** 흰 바탕, 부드러운 회보라 면, 큰 둥근 모서리를 써요. 그림자는 FAB와 다이얼로그에만 써요.

## 말투

- 해요체로 짧게 써요. "상대방과 연결해 주세요", "아직 일정이나 메모가 없어요"
- 버튼은 결과가 보이는 동사로 써요. "연결하고 시작하기", "코드 복사", "기본 색으로 되돌리기"는 좋고, "확인", "다음"만 쓰는 건 피해요.
- 빈 상태는 상황 설명과 할 수 있는 행동을 함께 줘요. "아직 일정이나 메모가 없어요 · + 이 날에 추가하기"
- 날짜는 `10월 12일 (월)`, 시간은 `오전 9:12` · `19:30`, 기념일은 `D+123` 형식이에요.
- 사람 호칭은 화면에서는 "나 / 상대 / 함께", 아바타 글자는 "나 / 너", 함께 원 안의 글자는 "둘"이에요.
- 이모지는 쓰지 않아요.

## 색

| 역할 | 토큰 | 규칙 |
|---|---|---|
| 브랜드 | `brand-500` | 주요 버튼, FAB, 선택된 날짜, 켜진 스위치, 포커스. 위 글자는 `on-brand` |
| 브랜드 글자 | `brand-700` | 흰 바탕 위 텍스트 버튼·링크 (`저장`, `완료`) |
| 브랜드 면 | `brand-100`, `brand-50` | 선택된 탭 알약, 고정된 핀 카드 |
| 사람 | `person-me`, `person-partner`, `person-together` | **기본값일 뿐**이에요. 실제 값은 사용자 설정에서 읽어요 |
| 글자 | `ink-900` → `ink-500` | 기본 → 본문 → 보조 → 3차 |
| 면 | `surface-0`, `surface-50`, `surface-100` | 화면 → 카드 → 트랙·패널 |
| 경계 | `line-300`, `line-200`, `line-100` | 입력 → 아웃라인 → 구분선 |
| 상태 | `danger-*`, `warning-*`, `favorite-600` | 오류·파괴, 주의, 즐겨찾기. 새 소식(안 읽음 점)은 `brand-500`이에요. `new-600`(새 글)·`info-700`(읽음)은 MVP에서 안 쓰지만 지우지 않았어요 (PRD v0.4 D-41) |

**사람 색 규칙**

- 사람 색은 점(8~14), 아바타, 캘린더 날짜 점에만 써요. 넓은 면이나 글자에는 쓰지 않아요.
- 사람 태그와 선택 버튼은 중립 면(`surface-0`, `line-200` 테두리)에 **색 점과 라벨**을 넣어요. 선택 상태는 사람 색이 아니라 `ink-900` 2px 테두리와 체크로 표시해서, 어떤 색을 골라도 똑같이 읽혀요.
- 사람 색 위의 글자(아바타 "나/너")는 배경 휘도로 정해요. WCAG 상대휘도가 0.2보다 크면 `ink-900`, 아니면 흰색이에요.
- 고를 수 있는 색은 `pick-*` 12색이에요. 두 대상이 같은 색이면 `warning-50` 배너로 알려줘요.

**접근성 메모**: `ink-500`은 흰 바탕에서만 4.5:1을 넘어요(`surface-100` 위에서는 `ink-600`을 써요). `line-300`과 `line-200`은 컨트롤 경계 3:1에 못 미쳐요. 지금 화면 그대로 두었지만, 경계만으로 상태를 전달하지 않도록 포커스·선택에는 `brand-500`이나 `ink-900` 2px를 써요.

## 크기와 간격

- 4dp 그리드를 써요(`space-1`~`space-8`). 화면 좌우 여백은 탭 화면 `space-5`(20), 온보딩 `space-6`(24)이에요.
- 고정 크기: 앱바 64, 하단 탭 80, FAB 56(오른쪽 20, 바닥에서 100), 텍스트 필드 52, 버튼 56/48/44예요. 로그인·계정 화면의 큰 버튼은 보드 값 54예요 (아래 "버튼").
- 터치 영역은 최소 44, 아이콘 버튼은 44~48이에요.
- 모서리는 작을수록 작은 요소에 써요. 배지 6, 칸 12, 입력·버튼 14, 카드 16~20, 패널·다이얼로그 24, 알약과 원은 full이에요.

## 아이콘

- 24 그리드 선 아이콘이에요. 선 굵기 1.8, 둥근 끝(round cap·join)을 쓰고 색은 `currentColor`를 따라요.
- 켜진 상태만 채워요. 핀은 `brand-500`, 별은 `favorite-600`으로 채우고, 꺼진 상태는 `ink-400` 선으로 그려요. 이 규칙은 핀·별처럼 켜고 끄는 아이콘에 써요. 하단 탭 아이콘은 선택돼도 채우지 않아요 (아래 "하단 탭").
- 아이콘 파일: 하단 탭의 달력·메모 아이콘은 `design/icons/tab-calendar.svg`, `design/icons/tab-memo.svg`예요 (보드 인라인 SVG를 그대로 옮김). 다른 아이콘 파일과 `components/bundle.css`·컴포넌트 README는 캔버스의 디자인 시스템에만 있고 Docs에는 아직 없어요. 그 전까지는 `design/source/` 보드의 인라인 SVG가 원본이에요.
- 아이콘만 있는 버튼에는 반드시 접근성 라벨을 붙여요(`contentDescription`, `aria-label`). 예: "전체 메뉴", "고정 해제", "즐겨찾기".
- 쓰는 아이콘: 햄버거(가로줄 3개), 알림 종, 뒤로·닫기, 더하기, 달력, 메모, 핀, 별, 팔레트, 복사, 공유, 시계, 링크, 사람이에요. 검색은 MVP에서 쓰지 않아요 (PRD v0.4 D-41).
- 알림 종류 아이콘은 새로 만들지 않고 위 아이콘에서 골라요. 짝은 아래 NotificationItem에 있어요.

## 컴포넌트

- **입력**: Button, TextField, CodeInput, Switch, SegmentedControl, ColorSwatch
- **선택**: Chip(필터 칩, 사람 선택, 사람 태그, 메모 날짜 칩)
- **피드백**: Dialog, Badge(안 읽음 점 포함)
- **표시**: Avatar, Card(일정 카드, 핀 카드, 패널), ListItem(메모 행, 메뉴 행), NotificationItem(알림 행)
- **이동**: TopAppBar, BottomNav, FAB

모든 컴포넌트의 스타일은 `components/bundle.css`의 `dr-` 클래스에 있어요. 각 컴포넌트 README에 상태와 규칙을 적었어요.

- **Material 3와 다른 점**: M3 `NavigationBar`의 기본값은 배경 `surfaceContainer`(이 매핑에서는 `surface-100`), 지시자 64×32, 비선택 색 `onSurfaceVariant`(`ink-600`)라 보드와 달라요. 지시자 크기는 바꿀 수 없으니 보드 값(알약 56×30)을 맞추려면 `core:designsystem` 컴포넌트로 그려요.

- "쓰지 않음"인 역할을 쓰는 M3 컴포넌트는 화면에 두지 않아요. 비워 두면 M3 기본색(보라 계열)이 남으니, 그 색이 화면에 보이면 매핑이 빠졌거나 M3 컴포넌트를 잘못 쓴 거예요.
- M3 기본값이 보드와 다른 컴포넌트는 `core:designsystem`에서 색을 직접 줘요.
  - 하단 탭: 위 "하단 탭" (배경 `surface-0`, 비선택 `ink-500`, 알약 56×30).
  - 바텀시트: M3 `ModalBottomSheet`의 기본 면은 `surfaceContainerLow`(`surface-50`)지만 보드는 흰색이에요 (`Calendar.dc.html` 137행, `StartDateSheet.dc.html` 20행, 위 모서리 24). 면을 `surface-0`으로 줘요.
  - 로딩 표시: 화면 전체를 `scrim`으로 덮고 가운데 판 84×84(`surface-0`, `radius-lg`, `shadow-dialog`)에 `CircularProgressIndicator`(크기 44, `strokeWidth` 4, `color` `brand-500`, `trackColor` `line-100`, 끝 `StrokeCap.Round`)를 놓아요. M3에 이런 덮개 컴포넌트는 없어서 `core:designsystem`에서 직접 그려요 (위 "로딩 표시").
  - 원형 진행 표시: `CircularProgressIndicator`(크기 `Modifier.size`, `strokeWidth`, `trackColor` `line-100`, `color` `brand-500`, `strokeCap` Round).
  - 당겨서 새로고침: `PullToRefreshBox`. 표시는 `indicator` 슬롯에 원판 44(`surface-0`, `shadow-sm`) + 원형 표시 24 / 선 2를 목록 위 64에 가운데로 놓아요 (위 "당겨서 새로고침").
  - 시간 휠: M3 `TimePicker`는 다이얼 방식이라 쓰지 않아요. 휠은 직접 구현해요 (줄 높이 44, 5줄 보임, 가운데 띠 `surface-100`). 위 "시간 휠".
  - 연도·월 선택: 월 칩은 선택 색이 `brand-500`이라(선택된 필터 칩은 `ink-900`) `FilterChip` 기본과 달라요. 보드 값(높이 40, `radius-full`)으로 `core:designsystem`에서 그려요 (위 "연도·월 선택", "일정 날짜 시트").
  - 입력: 보드의 입력창은 아웃라인형이에요 (`surface-0` 면 + `line-300` 1px, 모서리 14, 높이 52 — `AddEvent.dc.html` 35행). 채움형 `TextField`(면 `surfaceContainerHighest`)는 쓰지 않아요.
  - 선택된 필터 칩: 토큰 설명대로 `ink-900` 채움이에요 (M3 `FilterChip` 기본 `secondaryContainer`와 달라요).
- 사람 색은 `ColorScheme`에 넣지 않고 `PersonColors(me, partner, together)`를 `CompositionLocal`로 제공해요. 값은 서버나 DataStore의 커플 설정에서 읽어요.
  - **모르는 팔레트 키**: 12개 밖의 키를 받아도 오류로 보지 않아요. 값은 그대로 저장하고, 그릴 때 그 자리를 기본 사람 색 토큰(나 `person-me`, 상대 `person-partner`, 함께 `person-together`)으로 그리며 디버그 로그만 남겨요 (PRD v0.9, API.md 3.2).
- 타이포는 `Typography`에 이렇게 대응해요. `displayLarge`=`display`, `headlineMedium`=`headline`, `titleLarge`=`title-lg`, `titleMedium`=`title-md`, `titleSmall`=`title-sm`, `bodyLarge`=`body-lg`, `bodyMedium`=`body-md`, `bodySmall`=`body-sm`, `labelLarge`=`label`, `labelMedium`=`caption`, `labelSmall`=`micro`. 남는 자리(`displayMedium`·`displaySmall`·`headlineLarge`·`headlineSmall`)는 쓰지 않아요.
  - `display`는 로그인 앱 이름 "둘이서"에 써요 (`Main.dc.html` 27행, 40 · 행간 1.15 = 46 · 700 · -0.02em). `title-sm`은 목록 항목·섹션 제목 15/700이에요 (`Memo.dc.html` 25행).
  - `code-lg`·`code-md`는 M3에 고정폭 자리가 없어서 `Typography`에 넣지 않고 `core:designsystem`에 따로 둬요 (`font.mono`). 초대코드 칸에 써요: `code-lg` 26/500 (`InviteCreate.dc.html` 32행), `code-md` 24/500 (`InviteEnter.dc.html` 65행).
  - `letterSpacing`: 토큰에 있는 값은 em 그대로 써요 (Compose `TextUnit` `em`). `display` -0.02em, `headline`·`title-lg` -0.01em, `code-lg` 0.04em. 토큰에 없는 스타일(`title-md`·`title-sm`·`body-*`·`label`·`caption`·`micro`·`code-md`)은 **0**이에요 (보드도 지정하지 않음 = CSS 기본값).
- 모서리는 `Shapes`에 이렇게 대응해요. `small`=`radius-sm`, `medium`=`radius-md`, `large`=`radius-lg`, `extraLarge`=`radius-2xl`.
- 다크 모드는 아직 정의하지 않았어요(라이트 테마만 있어요).
