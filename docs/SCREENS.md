# 둘이서 화면 명세 (MVP v0.1)

> 기준 문서: 둘이서 PRD v0.7 (`docs/PRD.md`)
> 디자인 기준: **반영됨 (2026-10-22, 캔버스 버전 38, PRD v0.6)**. 19개 화면과 v0.6 상태 화면 모두 이미지가 있어요 (SCR-COUPLE-03 오류 문구, 재연결 복구 시트는 디자인 없음).
> 디자인 원본: claude.ai 디자인 캔버스 "커플 공유 앱 데모" (보드 대응표: `design/canvas-map.md`)
> 디자인 변경 요청서: `design/change-requests/prd-v0.6.md` (반영 완료, 캔버스 버전 38). 이전: `design/change-requests/prd-v0.5.md` (반영 완료, 캔버스 버전 35), `design/change-requests/prd-v0.4.md`
> 보드 원본: `design/source/` (정확한 크기·간격·색은 여기서 읽어요)
> 함께 보는 문서: `design/design-system.md`, `design/tokens.json`, `design/screens/`
> 작성일: 2026-10-17 · 갱신: 2026-10-26 (PRD v0.7 반영, 디자인 캔버스 버전 38)

이 문서는 PRD 5장 화면 목록의 화면별 명세예요. Android·iOS 에이전트는 화면을 만들 때 이 문서를 기준으로 하고, 이미지(`design/screens/<화면 ID>.png`)는 레이아웃 확인용으로 써요. 값과 문구가 이미지와 다르면 이 문서가 우선이에요. PRD와 충돌하면 PRD가 우선이에요.

**표기**
- `디자인: 반영됨`은 이미지가 있고 이 문서와 맞다는 뜻이에요.
- `디자인: 변경 요청됨 (PRD vX.Y)`는 디자인 변경 요청서로 수정을 요청했고 아직 캔버스에 반영되지 않았다는 뜻이에요. 기존 이미지는 레이아웃 참고용으로만 쓰고, 바뀐 부분은 이 문서를 따라요. 이미지가 없는 새 화면은 디자인이 나오기 전까지 구현하지 않아요. `이미지 예정 <이름>`은 요청서대로 새로 그릴 이미지의 이름이에요 (아직 `design/screens/`에 없어요).
- `차이:`는 디자인이 PRD와 다른 점이에요. **구현은 PRD를 따르고**, 차이는 사람이 정리할 때까지 그대로 둬요. PRD v0.4에서 대부분 해결됐어요. 전체 목록은 맨 아래 "PRD와의 차이"에 있어요.
- `디자인: 반영됨`이어도 이 문서에 PRD v0.5·v0.6에서 바뀐 동작이 적혀 있으면 그 동작은 이 문서를 따라요 (이미지에 없는 동작은 "디자인 없음"이나 "이미지 예정"으로 표시해요).
- 샘플 이름·숫자(`[상대 이름]`, `D+189` 등)는 자리표시예요. 실제 값으로 바꿔요.
- PRD에 있는 ID만 써요. 상태별 화면과 다이얼로그는 `SCR-…--<상태>.png`로 구분해요.
- 체크리스트, 메모 검색, 메모 읽음·NEW 표시, 우리 색상의 직접 색 고르기는 범위 밖이에요 (D-19, D-41). 화면에 넣지 않아요.

### SCR-COUPLE-02 초대코드 만들기

### SCR-COUPLE-04 연결 완료 시트

- **관련 FR**: FR-COUPLE-02, FR-COUPLE-03, FR-COUPLE-04, FR-COUPLE-06
- **진입**: 연결 직후 SCR-CAL-01 위에 하단 시트로 떠요 (두 사람 모두). 전체 화면이 아니에요 (D-49). 앱이 꺼져 있었거나 시트에서 고르지 않고 앱을 껐으면 다음 실행 때 SCR-CAL-01 위에 다시 떠요.
- **구성**: 제목 "[상대 이름]님과 연결됐어요", "처음 만난 날" 날짜 선택("날짜를 골라 주세요", 안내 "D-day와 기념일이 이 날을 1일로 계산돼요. 둘 중 누구든 나중에 바꿀 수 있어요.") + [나중에 하기], "혼자 쓴 기록" — 개수 안내와 [가져오기] / [가져오지 않기] 선택 카드, "내 기록만 정해요. 상대의 기록은 상대가 정해요.", [시작하기]
- **처음 만난 날**: 건너뛸 수 있어요. [나중에 하기]를 누르거나 고르지 않고 시작하면 SCR-CAL-01 D-day 자리에 처음 만난 날 입력 안내가 보여요. 고를 수 있는 날짜는 1950-01-01 ~ 오늘이에요. 오늘보다 뒤의 날짜와 1950-01-01보다 앞의 날짜는 고를 수 없어요 (FR-COUPLE-04 AC2·AC3, D-74). 둘 중 누구든 나중에 설정에서 바꿀 수 있어요.
- **혼자 쓴 기록**: 혼자 쓴 기록이 있으면 시트를 처음 열면 [가져오기]가 미리 선택돼 있어요 (FR-COUPLE-03 AC5, D-76). [가져오기]와 [가져오지 않기] 중 하나로 [시작하기]를 누르기 전에는 시트를 닫을 수 없어요. 밀어서 닫기, 뒤로 가기도 막아요 (FR-COUPLE-03 AC4). [가져오지 않기]로 시작하면 확인 다이얼로그가 떠요.
- **상태**
  - 혼자 쓴 기록이 있음: 위 구성 그대로 (`SCR-COUPLE-04.png`)
  - 혼자 쓴 기록이 없음: 기록 영역(제목, 개수 안내, 선택 카드, "내 기록만 정해요…" 안내)이 없고 시트를 닫을 수 있어요 — `SCR-COUPLE-04--no-records.png`
  - 유예 기간 안 재연결: 이전 공간이 복구되고 해제 후 새로 쓴 기록만 고름
  - 가져오기를 정하기 전에 연결이 해제되면: 혼자 쓴 기록은 원래 개인 공간으로 그대로 돌아가요 (FR-COUPLE-05 AC4, D-78)
- **동작**: [시작하기]를 누르면 시트가 닫히고 SCR-CAL-01이 그대로 보여요. 고른 처음 만난 날은 D-day와 자동 기념일에 바로 반영돼요.
- **다이얼로그**: "가져오지 않기"로 시작하면 "혼자 쓴 기록을 삭제할까요?" [취소] [삭제하고 시작] — `SCR-COUPLE-04--drop-dialog.png`
- **디자인**: 반영됨 (2026-10-22, 캔버스 버전 38) — `SCR-COUPLE-04--no-records.png`(기록 영역 없음, 제목 오른쪽에 닫기 버튼). 기존 시트와 다이얼로그 이미지는 그대로이고, [가져오기] 미리 선택은 v0.5 디자인대로 확정됐어요(D-76). 이전 반영분 (2026-10-22, 캔버스 버전 35, design/screens/SCR-COUPLE-04.png, SCR-COUPLE-04--drop-dialog.png) — 캘린더 위 하단 시트(위 모서리 24, 손잡이, 닫기 버튼 없음). 뒤의 캘린더 앱바는 "처음 만난 날 입력하기 ›". 이전 전체 화면 보드(Connected·ConnectedDialog)는 "(v0.4)"로 남겨 뒀어요.

## 알림

### SCR-NOTI-01 알림 목록

- **관련 FR**: FR-NOTI-05, FR-NOTI-03, FR-CAL-01
- **진입**: SCR-CAL-01 앱바의 알림 버튼
- **구성 (PRD 기준)**: 앱바(뒤로, "알림"), 최근 30일 알림 목록(최신순). 항목마다 종류 아이콘, 제목, 본문, 받은 시각, 안 읽음 점
- **알림 종류**: 일정 알림, 상대 일정·메모 추가, 메모 고정, 기념일, 연결, 해제(상대 탈퇴로 인한 해제 포함) (PRD 8장). 푸시를 끈 종류도 목록에는 나와요.
- **동작**: 항목을 누르면 읽음 처리되어 안 읽음 점이 사라지고, 관련 화면으로 이동해요.

  | 알림 | 이동 |
  | --- | --- |
  | 일정 알림, 상대 일정 추가 | SCR-CAL-02 |
  | 상대 메모 추가, 메모 고정 | SCR-MEMO-03 |
  | 기념일 | SCR-ANNIV-01 |
  | 연결, 해제, 상대 탈퇴 | 설정 (SCR-SET-01) |

  - 대상 일정·메모가 이미 삭제됐으면 읽음 처리만 하고 목록에 머물며 "삭제된 일정이에요" 또는 "삭제된 메모예요"를 짧게 보여줘요 (PRD FR-NOTI-05 AC5, D-43).
- **문구**: 항목의 제목·본문은 PRD 8장 "알림 문구" 표를 따라요 (D-46). 예: "[상대 이름]님이 일정을 추가했어요" / "10월 17일 (토) · 1박 2일 여행". 푸시와 같은 문구예요.
  - 자동 기념일: "오늘은 200일이에요" / "함께한 지 D+200"
  - 직접 기념일: "오늘은 [기념일 이름]이에요" / 매년 반복이고 두 번째 해부터는 "[N]번째 맞는 날이에요", 그 밖에는 "오늘이에요" (D-55)
  - 연결 해제: "[상대 이름]님이 연결을 해제했어요" / "30일 안에 다시 연결하면 기록이 돌아와요"
  - 상대 탈퇴: "[상대 이름]님이 탈퇴해 연결이 해제됐어요" / "함께 쓴 기록은 더 이상 볼 수 없어요". 복구 안내가 없어요 (D-53).

- **상태**
  - 비어 있음: "최근 30일 동안 받은 알림이 없어요"
  - 안 읽음: 항목에 점이 보이고, 읽으면 점이 사라져요. 모든 항목을 읽으면 SCR-CAL-01 알림 버튼의 점도 사라져요.
- **규칙**: 30일이 지난 알림은 목록에서 사라져요. 알림은 각자의 것이라 상대에게 보이지 않아요. 연결을 해제하면 그 공간에서 온 알림은 목록에서 지워지고, 연결·해제 알림만 남아요 (PRD D-45).
- **디자인**: 반영됨 (2026-10-22, 캔버스 버전 35, design/screens/SCR-NOTI-01.png, SCR-NOTI-01--read.png, SCR-NOTI-01--empty.png, SCR-NOTI-01--withdrawn.png) — 기념일 알림 두 가지(자동 "오늘은 200일이에요 / 함께한 지 D+200", 직접 "3번째 맞는 날이에요"). 상대 탈퇴 알림은 해제 뒤 목록(연결·해제 알림만 남음, D-45)을 따로 그렸어요.
