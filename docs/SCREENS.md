# 둘이서 화면 명세 (MVP v0.1)

> 기준 문서: 둘이서 PRD v0.3 (`docs/PRD.md`)
> 디자인 기준: **미반영**. PRD만으로 만든 초안이에요. 디자인 수정 후 `/design-handoff`가 각 화면의 구성·문구·이미지를 디자인 기준으로 채워요.
> 함께 보는 문서: `design/design-system.md`, `design/tokens.json`, `design/screens/`
> 작성일: 2026-10-17

이 문서는 PRD 5장 화면 목록의 화면별 명세예요. Android·iOS 에이전트는 화면을 만들 때 이 문서를 기준으로 하고, 이미지(`design/screens/<화면 ID>.png`)는 레이아웃 확인용으로 써요. 값과 문구가 이미지와 다르면 이 문서가 우선이에요. PRD와 충돌하면 PRD가 우선이에요.

**표기**
- `디자인: 미반영`은 아직 디자인 이미지가 없다는 뜻이에요. 그 화면을 구현하려면 핸드오프가 먼저 돼야 해요.
- 문구는 PRD에 정해진 것만 적었어요. 나머지 문구는 핸드오프 때 디자인에서 가져와요.
- 새 ID를 만들지 않아요. 다이얼로그와 시트는 해당 화면 아래에 적어요.

## 캘린더

### SCR-CAL-01 캘린더 홈

- **관련 FR**: FR-CAL-01, FR-ANNIV-01, FR-ANNIV-02, FR-COUPLE-04
- **진입**: 앱 진입 기본 화면, 하단 탭
- **구성 (PRD 기준)**: 상단 앱바(전체 메뉴 햄버거), 커플이면 D+N, 월간 달력(오늘 달·오늘 선택), 날짜별 표시 점, 선택한 날의 목록(종일 일정·기념일 먼저, 그다음 시작 시간순), 일정 추가 FAB
- **상태**
  - 개인 공간: D-day 없음
  - 커플 + 사귄 날 없음: D-day 자리에 사귄 날 입력 안내
  - 선택한 날 비어 있음: "아직 일정이나 메모가 없어요 · + 이 날에 추가하기" (디자인 시스템 말투 예시)
- **디자인**: 미반영

### SCR-CAL-02 일정 상세

- **관련 FR**: FR-CAL-03, FR-CAL-05
- **진입**: 일정 선택, 일정 알림 푸시
- **구성 (PRD 기준)**: 제목, 일시(종일이면 날짜만), 대상(나·상대·함께, 보는 사람 기준), 일정 메모, 작성자 닉네임, 내 일정 알림 설정
- **권한**: 수정·삭제는 작성자에게만. 대상이 '함께'면 두 사람 모두
- **일정 알림 선택지**: 시간 일정은 없음·정시·10분 전·1시간 전·1일 전, 종일 일정은 없음·당일 오전 9시·1일 전 오전 9시. 내 설정만 보임
- **다이얼로그**: 삭제 확인
- **디자인**: 미반영

### SCR-CAL-03 일정 작성·수정

- **관련 FR**: FR-CAL-02, FR-CAL-03, FR-NOTI-04
- **진입**: SCR-CAL-01의 추가 버튼, SCR-CAL-02의 수정
- **구성 (PRD 기준)**: 제목(필수), 종일 스위치, 시작·종료 일시, 대상 선택(나·함께, 기본 나), 일정 메모, 일정 알림, "상대에게 알림 보내기" 스위치(기본 켜짐)
- **조건**
  - 개인 공간: 대상 선택과 "상대에게 알림 보내기" 스위치가 보이지 않음
  - 수정할 때: "상대에게 알림 보내기" 스위치가 보이지 않음 (수정은 알림을 보내지 않음)
  - 대상에 '상대'는 없음 (D-34)
- **오류**: 종료가 시작보다 이르면 저장되지 않고 오류 표시
- **디자인**: 미반영

## 메모

### SCR-MEMO-01 메모 목록

- **관련 FR**: FR-MEMO-01, FR-MEMO-05, FR-MEMO-06
- **진입**: 하단 탭
- **구성 (PRD 기준)**: 상단 고정 영역, 보기 선택(최신순·오래된순·즐겨찾기), 일반 목록, 메모 추가 FAB
- **목록 항목**: 제목(없으면 본문 첫 줄), 작성자 닉네임, 작성일, 체크리스트 진행(예: 2/5)
- **고정 영역**: 고정 3개 이하면 모두 표시하고 "더보기" 없음. 4개 이상이면 최근 고정한 3개 + "더보기". 고정된 메모는 일반 목록에 다시 나오지 않음. 고정 개수 제한 없음
- **디자인**: 미반영

### SCR-MEMO-02 고정 메모 전체

- **관련 FR**: FR-MEMO-05
- **진입**: SCR-MEMO-01의 "더보기" (고정 4개 이상일 때만)
- **구성 (PRD 기준)**: 고정된 메모 전체, 최근 고정순
- **디자인**: 미반영

### SCR-MEMO-03 메모 상세

- **관련 FR**: FR-MEMO-03, FR-MEMO-04, FR-MEMO-05, FR-MEMO-06
- **진입**: 메모 선택, 메모 추가·고정 푸시
- **구성 (PRD 기준)**: 제목, 본문, 체크리스트(체크 가능), 고정 버튼, 즐겨찾기 버튼, 작성자 닉네임
- **권한**: 체크 표시와 고정은 두 사람 모두. 수정·삭제는 작성자만. 즐겨찾기는 각자 (상대에게 안 보임)
- **다이얼로그**: 삭제 확인
- **디자인**: 미반영

### SCR-MEMO-04 메모 작성·수정

- **관련 FR**: FR-MEMO-02, FR-MEMO-03, FR-MEMO-04, FR-NOTI-04
- **진입**: SCR-MEMO-01의 추가 버튼, SCR-MEMO-03의 수정
- **구성 (PRD 기준)**: 제목, 본문, 체크리스트 항목(추가·수정·삭제·순서 변경), "상대에게 알림 보내기" 스위치(기본 켜짐)
- **조건**: 셋 다 비어 있으면 저장되지 않음. 개인 공간과 수정할 때는 알림 스위치가 보이지 않음
- **디자인**: 미반영

### SCR-COUPLE-01 커플 연결 (연결 방법 선택)

- **구성 (PRD 기준)**: "초대코드 만들기", "초대코드 입력하기", "혼자 시작하기"
- **게스트가 들어온 경우**: 연결 화면 대신 계정 연동이 필요하다는 안내와 연동 버튼 (FR-AUTH-04)
- **디자인**: 미반영

- **관련 FR**: FR-COUPLE-01
- **구성 (PRD 기준)**: 8자리 코드(영문 대문자·숫자, 0·O·1·I 제외, IBM Plex Mono), 남은 유효 시간(24시간 기준), 공유, 재발급
- **디자인**: 미반영

### SCR-COUPLE-03 초대코드 입력하기

- **관련 FR**: FR-COUPLE-02
- **구성 (PRD 기준)**: 코드 입력(8자리)
- **오류 (각각 다른 문구)**: 존재하지 않는 코드, 만료된 코드, 이미 사용된 코드, 자신이 만든 코드, 사용할 수 없는 코드(만든 사람이 이미 다른 사람과 연결됨), 1시간 10회 실패로 입력 제한
- **디자인**: 미반영

### SCR-COUPLE-04 연결 완료

- **관련 FR**: FR-COUPLE-03, FR-COUPLE-04, FR-COUPLE-06
- **진입**: 연결 성공 직후 (두 사람 모두)
- **구성 (PRD 기준)**: 연결 완료 안내, 사귄 날 입력, 내 기존 기록 "가져오기 / 가져오지 않기"
- **조건**: 각자 자기 데이터만 고름. 유예 기간 안에 재연결이면 이전 커플 공간이 복구되고, 해제 후 새로 만든 데이터만 가져올지 고름
- **다이얼로그**: "가져오지 않기" 확인 (개인 공간 데이터가 삭제됨)
- **디자인**: 미반영

## 설정

### SCR-SET-01 전체 메뉴 (설정)

- **관련 FR**: FR-SET-01, FR-AUTH-03, FR-AUTH-04, FR-AUTH-05, FR-AUTH-06, FR-COUPLE-05
- **진입**: 캘린더 상단 햄버거 메뉴
- **구성 (PRD 기준)**: 프로필(이름·사진), 우리 색상, 계정(로그인 수단, 게스트면 연동), 커플(연결 상태, 상대 닉네임, 사귄 날, 연결 또는 해제), 알림 설정, 로그아웃(회원만), 탈퇴, 앱 버전
- **게스트**: 상단에 "앱을 삭제하거나 기기를 바꾸면 데이터를 복구할 수 없습니다" 안내와 계정 연동 버튼이 항상 보임. 로그아웃 메뉴 없음
- **다이얼로그**
  - 로그아웃 확인
  - 연결 해제 확인: 해제하면 두 사람 모두 빈 개인 공간에서 다시 시작하고, 30일 안에 다시 연결하면 복구됨. 해제 후 앱이 초기화되고 SCR-COUPLE-01로 이동 (FR-COUPLE-05)
  - 탈퇴 확인: 개인 공간이면 즉시 삭제, 커플 공간이면 연결 해제 후 삭제 (FR-AUTH-06)
  - 이미 가입된 소셜 계정으로 연동 시도 시 안내 (FR-AUTH-03)
- **디자인**: 미반영
