# 둘이서 화면 명세 (MVP v0.1)

> 기준 문서: 둘이서 PRD v0.3 (`docs/PRD.md`)
> 디자인 기준: **부분 반영 (2026-10-18)**. 18개 화면 중 15개 반영, 3개 디자인 없음 (SCR-CAL-02, SCR-MEMO-03, SCR-SET-02)
> 디자인 원본: claude.ai 디자인 캔버스 "커플 공유 앱 데모" (보드 대응표: `design/canvas-map.md`)
> 함께 보는 문서: `design/design-system.md`, `design/tokens.json`, `design/screens/`
> 작성일: 2026-10-17 · 갱신: 2026-10-18 (디자인 핸드오프)

이 문서는 PRD 5장 화면 목록의 화면별 명세예요. Android·iOS 에이전트는 화면을 만들 때 이 문서를 기준으로 하고, 이미지(`design/screens/<화면 ID>.png`)는 레이아웃 확인용으로 써요. 값과 문구가 이미지와 다르면 이 문서가 우선이에요. PRD와 충돌하면 PRD가 우선이에요.

**표기**
- `디자인: 반영됨`은 이미지가 있다는 뜻이에요. `디자인 없음`인 화면은 디자인이 나오기 전까지 구현하지 않아요.
- `차이:`는 디자인이 PRD와 다른 점이에요. **구현은 PRD를 따르고**, 차이는 사람이 정리할 때까지 그대로 둬요. 전체 목록은 맨 아래 "PRD와의 차이"에 있어요.
- 샘플 이름·숫자(`[상대 이름]`, `D+189` 등)는 자리표시예요. 실제 값으로 바꿔요.
- 새 ID를 만들지 않아요. 상태별 화면과 다이얼로그는 `SCR-…--<상태>.png`로 구분해요.
