# PRD v0.21 영향 분석

> 상태: PR 완료

> 브랜치: sync/prd-v0.21
> PR: (PR을 연 뒤 번호)

이 파일은 `/prd-sync` 팀원들이 읽는 계약이다. 여기 적힌 이름과 할 일을 그대로 따른다.

진행 방식: **팀** (ERD, API, SCREENS, 디자인 요청서를 모두 고친다).
사용자 결정: 2026-11-25. 메모와 캘린더를 나눈다. 메모 날짜는 DB 컬럼까지 완전히 지운다. 아래 문구 4개를 바꾼다. 알림 종류 "상대 일정·메모 추가"의 이름은 그대로 둔다.

## 4. 위험 항목

- [x] **DB 마이그레이션 필요**: `memos.memo_date`와 부분 인덱스를 지운다. 이미 머지된 마이그레이션은 고치지 않고 새 Flyway 버전을 추가한다 (Server 레포).

- [ ] 권한 변경: 없음
- [x] **앱 호환성이 깨지는 API 변경**: `GET /memos/dated`와 `memoDate`가 없어진다. 출시 전이라 이전 앱 버전을 지원하지 않는다. 서버와 Android를 같은 시기에 배포한다.
