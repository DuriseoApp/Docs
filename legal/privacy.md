# 둘이서 개인정보처리방침

> **초안 (법률 검토 전)** · PRD v0.13 D-154 · 게시 전 사용자가 검토하고, 필요하면 전문가 확인을 받는다.
> 시행일: [시행일]

둘이서(이하 "서비스")를 운영하는 주성현(이하 "운영자")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

## 1. 처리하는 개인정보 항목

| 구분 | 항목 | 수집 방법 |
| --- | --- | --- |
| 계정 | 사용자 ID(앱이 만든 무작위 값), 계정 종류(게스트·회원), 로그인 수단(Google·카카오)과 그 수단의 고유 식별자 | 시작할 때, 소셜 계정 연동 때 |
| 프로필 | 이름(닉네임), 프로필 사진(이용자가 올린 경우), 표시 색상 | 이용자 입력 |
| 이용자가 만든 기록 | 일정, 기념일, 처음 만난 날, 메모, 즐겨찾기, 일정 알림 설정 | 이용자 입력 |
| 커플 연결 | 연결한 상대, 연결·해제 시각, 초대코드와 오입력 기록 | 커플 연결 때 |
| 기기·알림 | 푸시 알림 토큰(FCM), 기기 시간대, 알림 종류별 설정, 받은 알림 목록 | 앱 실행·알림 설정 때 자동 |
| 이용 기록 | 로그인 세션(만료 시각, 마지막 사용 시각) | 서비스 이용 중 자동 |

- 소셜 로그인에서는 그 서비스의 고유 식별자만 받고, 이메일·전화번호는 받지 않습니다.
- 프로필 사진의 위치 정보 등 사진 정보(EXIF)는 저장할 때 지웁니다.

## 2. 처리 목적

- 회원 식별과 로그인 유지, 한 기기 로그인 관리
- 커플 공간에서 일정·기념일·메모를 상대와 함께 보여 주는 서비스 제공
- 일정·기념일·상대 활동 알림 보내기
- 부정 이용 방지(초대코드 오입력 제한), 장애 대응과 복구
- 문의 응대

## 3. 보유 기간과 파기

| 대상 | 보유 기간 |
| --- | --- |
| 회원 정보와 개인 공간의 기록 | 탈퇴할 때까지. 탈퇴하면 즉시 삭제 |
| 커플 공간의 기록 | 연결 해제 뒤 30일(다시 연결하면 복구). 탈퇴로 해제된 경우 탈퇴 뒤 90일 보관 후 삭제 (장애 복구 목적) |
| 게스트 | 마지막 사용 뒤 365일이 지나면 탈퇴와 같이 삭제 |
| 알림 목록 | 받은 뒤 30일 |
| 초대코드 오입력 기록 | 7일 |
| 데이터베이스 백업 | 30일 |

- 탈퇴하면 이름은 "탈퇴한 사용자"로 바뀌고, 프로필 사진·로그인 수단·세션·기기·알림 설정·알림 목록·즐겨찾기·일정 알림은 삭제됩니다. 상대와 함께 쓴 커플 공간의 기록은 위 기간 동안 상대에게 "탈퇴한 사용자"가 쓴 것으로 남습니다.
- 기간이 지난 정보는 매일 정리 작업으로 복구할 수 없게 삭제합니다.

## 4. 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 단, 이용자가 연결한 커플 상대에게는 서비스의 기능으로 이름, 프로필 사진, 색상, 커플 공간의 기록이 보입니다.

| --- | --- | --- | --- | --- |

## 6. 이용자의 권리

- 이용자는 언제든지 앱에서 이름·사진을 고치고, 기록을 지우고, 알림을 끄고, 탈퇴할 수 있습니다 (전체 메뉴 › 계정 › 탈퇴하기).
- 앱을 쓸 수 없으면 열람·정정·삭제·처리 정지를 9장의 개인정보 보호책임자(접수 창구와 같음)에게 메일로 요청할 수 있습니다. 운영자는 본인 확인 뒤 지체 없이 처리합니다.

## 7. 만 14세 미만

서비스는 만 14세 이상만 이용할 수 있습니다. 만 14세 미만의 개인정보는 수집하지 않으며, 알게 되면 지체 없이 삭제합니다.

## 8. 안전성 확보 조치

- 서버와 앱 사이의 통신은 암호화(HTTPS)합니다.
- 로그인 토큰은 기기에 암호화해 저장하고 서버에는 해시만 저장합니다.
- 데이터베이스와 저장소는 공개 접근을 막고, 운영자만 접근합니다.
- 다른 커플 공간의 기록에는 접근할 수 없도록 모든 요청에서 권한을 검사합니다.
