# 둘이서 계정 삭제 안내

> **초안 (법률 검토 전)** · PRD v0.13 D-154, FR-AUTH-09 · Google Play Console의 "계정 삭제 URL"에 이 페이지 주소를 등록한다.

둘이서(운영: jucoding)의 계정과 데이터를 지우는 방법이에요.

## 앱에서 지우기

1. 둘이서 앱을 열어요.
2. 캘린더 상단의 전체 메뉴 버튼 › **계정** › **탈퇴하기**를 눌러요.
3. 안내를 확인하고 탈퇴해요. 카카오로 로그인했다면 카카오와의 연결도 함께 끊어져요.

## 앱을 쓸 수 없을 때

**jucoding99@gmail.com**으로 메일을 보내 주세요. 본인 확인을 위해 아래를 적어 주세요.

- 로그인 수단(Google 또는 카카오)과 앱에 보이는 이름. 로그인 수단으로 본인을 확인하는 방법은 답장으로 안내해 드려요
- 게스트라면 앱의 계정 화면에 보이는 게스트 ID (게스트는 본인 확인 수단이 없어서, 게스트 ID를 모르면 삭제를 도와드리기 어려워요)

확인한 뒤 지체 없이 지우고 메일로 알려 드려요.

## 지워지는 것과 남는 것

| 데이터 | 처리 |
| --- | --- |
| 프로필(이름·사진), 로그인 수단, 기기·알림 설정, 알림 목록, 즐겨찾기, 일정 알림 | 바로 삭제 |
| 혼자 쓴 기록(개인 공간) | 바로 삭제 |
| 커플 상대와 함께 쓴 기록(커플 공간) | 상대에게 "탈퇴한 사용자"가 쓴 것으로 **90일** 남았다가 삭제 (장애 복구 목적) |
| 서버 백업 | 최대 **30일** 뒤 삭제 |

일부 데이터만 지우고 싶다면 앱에서 일정·기념일·메모를 직접 지우거나, 프로필 사진을 기본 이미지로 바꿀 수 있어요.
